# @deepseek-ai/dsh-client-ui-rlm

[English](README.md) | 中文

RLM `verify` 与 `moa` 工具的 Web 工具行。每一行都是基于持久化调用/结果切片的带键 `tool.call.toolview`：一个紧凑摘要，其状态反映 judge/参考的降级情况，并可展开查看完整渲染输出。

## 模型体验

### verify 与 moa 工具行

#### 模型看到什么

行本身不向模型展示任何新内容：它只读取 `verify` 与 `moa` 工具的冻结调用/结果切片，因此重放与刷新保持稳定。降级从宿主渲染器已经产出的结果文本中检测（`verify`："N judge(s) degraded or failed (...)"，`moa`："N reference(s) failed (...)"）。

#### Token 影响

该行不增加任何模型 token；它纯粹是对已发出工具结果的客户端呈现。

#### KV 缓存影响

在请求路径上无状态：它从持久化调用切片渲染，从不修改更早的请求 token。

### 生命周期状态

#### 模型看到什么

运行中的调用显示持续闪烁的圆点与"运行中"；失败的调用显示首行错误与错误样式；已停止的调用显示停止状态；轨迹 Inspect 按钮在可用时打开该调用。

#### Token 影响

无 token：这些状态是工具调用生命周期的客户端投影。

#### KV 缓存影响

无请求 token 影响；该行从不抵达模型。

## 已知限制与待办工作

- 警告是从渲染器输出按文本派生的，因此依赖宿主工具渲染器在结果文本中保留降级标记；未来的结构化结果投影可让该行直接读取失败的 judge/参考字段，而无需解析文本。
